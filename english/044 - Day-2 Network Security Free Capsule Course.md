- **ARP (the day's payload):** inside a LAN, delivery runs on **MAC, not IP**; every device keeps an **IP↔MAC table (ARP table)**; flow = broadcast **ARP request** ("who has 192.168.29.13? tell me — here's my MAC") → everyone else ignores → owner **ARP-replies** with its MAC → stored in the table → subsequent packets go by MAC. **Switch** tables map **MAC → physical port** (switches don't use IP); **router** steps in for network-to-network (NAT boundary).
- **DHCP:** Dynamic Host Configuration Protocol; the four-packet dance — **DISCOVER (broadcast) → OFFER ("take 192.168.1.210") → REQUEST ("I'll take it") → ACK (final)**; router doubles as home DHCP server; **Lease Obtained / Lease Expires** = Day-1's dynamic-vs-static concept made visible.
